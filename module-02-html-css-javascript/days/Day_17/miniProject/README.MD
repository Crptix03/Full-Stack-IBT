Explainning how the balance in loyaltyModule.js stays private:- is because points is declared as a local variable inside creatLoyalty(), not as a property on the returned object, so it only exists in that function's scope. The returned methods (earn, redeem, balance) form a closure, meaning they keep access to that same points variable even after creatLoyalty() has finished executing, while nothing outside the function can reference it directly — there's no card.points to read or write, since JavaScript never exposes local variables outside their scope. This makes points effectively private: the only way to interact with it is through the exposed methods, and each call to creatLoyalty() creates its own independent, isolated points variable.

# Habesha Eatery Website

## Project Summary
This project includes a restaurant website with a homepage, contact page, and reservation page, all styled with `styles.css`.

## Pages and Features
- `index.html`
  - Hero section with welcome text and buttons.
  - About section with restaurant story, stats, and featured menu items.
  - Menu cards showing dish details and prices.
- `contact.html`
  - Contact form for name, email, and message.
  - Embedded Google Map for location.
- `reserve.html`
  - Reservation form for name, email, phone, party size, and special requests.

## Styling (`styles.css`)
- Sticky top navigation with responsive links.
- Hero section with background image and button styles.
- Card grid layout for menu items.
- Form styling for inputs, textarea, and submit button.
- Footer layout with links and copyright text.
- Responsive design for tablet and mobile screens.

## Notes
- Navigation is consistent across all pages.
- Some image and link paths are local and may need adjustment when moving the project.
- Forms are static HTML forms and do not send data without added backend logic.
